# 变更日志

## 0.1.0-rc1 — 2026-09-07

派生自规范夜间冻结包 FREEZE_QWEN_OVERNIGHT_20260907（内含 SHA256SUMS；见
freeze/package_SHA256SUMS）的候选发布版本。

新增（随机通道，分支 stoch-engine-0907，基于 420bca8）：

- Philox4x32-10 计数器式 GPU RNG，按项目冻结的 RNG 规范实现，主机与设备两侧均通过
  已知答案测试。
- 加权统计归约原语（N、Σw、Σw²、Σw f、Σw f²、log-sum-exp、ESS；fp64；多观测量），
  以 CPU 参考验证。
- 融合蒙特卡洛门 MC-A、MC-A2（加权）、MC-B，以及分层 MC-A3（与 MC-A 等时下误差低约
  188 倍）。
- 合成受条件 Kolmogorov 场：分叉、带权重补偿的击杀硬币剪枝、排他扫描压缩、融合观测量、
  三个解析门、密度渲染工件。
- 模型支撑的受条件随机场（MC-C）：常驻父状态 M=8 分叉，贪婪控制行 + 温度 1 采样行，16 步，
  逐行状态签名观测量（增量开关 QF_M8_FORK_SIG），无权场统计。
- 合成场吞吐刻画（M≥262,144 时 1.6e9 轨迹步/秒）。

改动（生产通道，分支 m1-30tok-0907，基于 420bca8）：

- B1：QSA 索引器打分域在 T=1 时按分配上限取值（图捕获冻结了由主机导出的候选计数；生成期间
  新建的块从未被打分）。门：修复后图捕获解码 vs 急切解码，300/300 token 一致。
- B2：精确单遍基数 top-512 选择器，替换 48 步阈值二分，平局语义完全一致。门：13 用例单元
  测试 + memcheck + 300/300 token 一致回执；尾部 23.5 → 23.1 ms/token。
