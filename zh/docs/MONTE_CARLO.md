# 蒙特卡洛积分

引擎的数值核心以具有闭式解的积分验证。所有门把采样、被积函数求值与归约融合进一个内核；
CPU 从不逐样本迭代。RNG：按冻结规范的 Philox4x32-10。归约：Dumitrescu 原语（fp64）。
硬件：NVIDIA GB10，时钟锁定。全程 seed 42。回执（权威）：
receipts/MC_GATES_RECEIPT_20260907.md。

## MC-A — 标量健全性

问题：X ~ U(0,1) 的 E[X²]。解析值：1/3。被积函数 f(x)=x²。无权。N=1,048,576。
估计 0.333674980。|误差| = 3.4e-4（期望 1-sigma 约 2.9e-4）。用时 1.9 ms；约 5.4e8 样本/s。

## MC-A2 — 加权（重要性采样）

同一积分，从 q(x)=2x 重要性采样：x=sqrt(u)，w=1/(2x)。估计 0.333907284，|误差| = 5.7e-4，
ESS 约 3.1e5。端到端锻炼加权路径（对数权重、加权矩、ESS 报告）。

## MC-B — 多维

问题：[0,1)^16 上的 E[Σ_j X_j²]。解析值：16/3。每样本 16 个均匀量（每次调用 4 个 Philox 字）。
N=262,144。估计 5.334712595，|误差| = 1.4e-3。用时 0.65 ms；约 4.1e8 样本/s。锻炼向量化
RNG 与多观测量归约。

## MC-A3 — 分层（方差缩减）

分层/抖动采样，S=64 层：u = (层号 + uniform)/64。与 MC-A 同一积分。N=1,048,576。
估计 0.333335152，|误差| = 1.8e-6——与普通 MC-A 在对比墙钟时间（均约 1.9 ms）下绝对误差低
约 188 倍。这是保留的方差缩减机制。它不是“蒙特卡洛快 188 倍”，而是等时下误差低 188 倍。
回执：receipts/VARIANCE_REDUCTION_RECEIPT_20260907.md。

## 为什么这个指标重要

对这类系统，样本/s 单独不完整。重要的量是样本/s、有效样本/s、估计量误差、固定墙钟下的
估计量误差、ESS 与轨迹/s。优化目标是每秒统计工作量，而不只是每秒 token 或样本。分层结果是
具体演示：同样的墙钟，两个数量级的误差下降，只改采样规则。

## 模型支撑（MC-C）

从合成积分到常驻模型积分的桥梁是 MC-C，见 docs/STOCHASTIC_ENGINE.md 与
receipts/MCC_MODEL_FIELD_RECEIPT_20260907.md：一个常驻父状态、七个温度 1 随机子分支、一个
贪婪对照、十六步、状态签名观测量，归约为场统计。模型受条件观测量没有闭式解；那里的门是
确定性种子重放加贪婪对照，且 M>8 异常作为局限而非结果记录。
