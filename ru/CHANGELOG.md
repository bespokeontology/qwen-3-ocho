# Журнал изменений

## 0.1.0-rc1 — 2026-09-07

Кандидат в релиз, производный от канонического ночного фриз-пакета
FREEZE_QWEN_OVERNIGHT_20260907 (с внутренними SHA256SUMS; см. freeze/package_SHA256SUMS).

Добавлено (стохастическая линия, ветка stoch-engine-0907 от 420bca8):

- Счётчиковый GPU-ГПСЧ Philox4x32-10 по замороженной спецификации проекта; тест с известным
  ответом на хосте и устройстве.
- Примитив взвешенной статистической редукции (N, Σw, Σw², Σw f, Σw f², log-sum-exp, ESS;
  fp64; несколько наблюдаемых) с валидацией по CPU-эталону.
- Слитные гейты Монте-Карло MC-A, MC-A2 (взвешенный), MC-B и стратифицированный MC-A3
  (≈188x меньше ошибки при равном времени по сравнению с MC-A).
- Синтетическое условное поле Колмогорова: форк, прореживание монетой смерти с весовой
  компенсацией, уплотнение исключающим сканом, слитные наблюдаемые, три аналитических гейта,
  артефакт рендеринга плотности.
- Условное стохастическое поле на модели (MC-C): форк M=8 резидентного родителя, жадная
  контрольная строка, строки с сэмплированием температуры 1, 16 шагов, сигнатуры состояния на
  строку (аддитивный переключатель QF_M8_FORK_SIG), невзвешенная статистика поля.
- Характеристика пропускной способности синтетического поля (1.6e9 шагов-траекторий/с при
  M≥262 144).

Изменено (продуктовая линия, ветка m1-30tok-0907 от 420bca8):

- B1: область скоринга QSA-индексатора при T=1 ограничена максимумом аллокации (захват графа
  замораживал выведенный с хоста счётчик кандидатов; блоки, созданные во время генерации,
  никогда не скорились). Гейт: захваченный граф против eager-декодирования после исправления —
  300/300 токенов идентичны.
- B2: точный однопроходный radix-отбор top-512 вместо 48-шаговой пороговой бисекции, с
  идентичной семантикой равенств. Гейт: юнит-набор из 13 случаев + memcheck + чек 300/300
  токенов; хвост 23.5 → 23.1 мс/токен.

Отложено (AMD, без интеграции):

- B3: порт того же селектора в AMD top-k ядра: HIP-юнит-валидация (10/10 нетривиальных случаев
  точны). Интеграция отложена: точное дерево исходников замороженного продуктового бинарника
  AMD (824e5c50) не восстановлено, а пересборки из доступного зеркала расходятся на токене 0
  с radix-селектором и без него.

Известные ограничения: см. docs/LIMITATIONS.md.
