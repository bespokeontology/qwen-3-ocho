# Префилл и резидентная доливка

Эти механизмы были заморожены до ночной стохастической работы и описаны здесь потому, что они
задают смысл «резидентного состояния» в этой системе. Все числа — из более ранних канонических
фризов (FREEZE_QWEN_PREFILL_1543_20260906 и чек доливки); в этом окне ничего не менялось.

## Замороженный префилл

Продуктовый гетерогенный префилл, промпт 8 038 токенов, логические чанки T=2048, AMD-префикс +
хвост Spark: **5.21 с ≈ 1 543 tok/s** (полоса того же бинарника 5.21-5.42 с). Сохранённая
прогрессия, по одному чеку 8K на принятый шаг:

| шаг | прогрев |
|---|---|
| два AMD-чанка в полёте | 6.02 с |
| слитный HC/роутер-клей | 5.78 с |
| слитный GDN-пост | 5.70 с |
| AMD union-tile QSA | 5.44 с |
| пакетный CSR + проход экспертов по 64 токена | 5.26 с |
| финальный продуктовый чек | 5.21 с |

Более ранние чеки тех же бинарников: 382 токена за 0.85 с; 2 038 токенов за 2.18 с; 5 038
токенов за 4.35 с. Заведомо худшие варианты (первый чанк 512, деление хвоста пополам, 8-warp
формы экспертов, последовательный GDN, ручной fp8 GEMM, внимание list-ядром, по-позиционное
AMD QSA) остаются выключенными по умолчанию и описаны во фризе.

## Резидентная доливка / инъекция контекста

Доливка вводит дополнительный контекст в резидентное состояние без повтора: область инъекции
обрабатывается чанками через путь префилла; продолжение с выходного состояния возобновляет
декодирование. Действует правило времени жизни графа: захваченный хвостовой граф
инвалидируется при инъекции и перезахватывается (~4 мс). Измерено: 136 токенов за 0.60 с
(TTFT 0.65 с); 2 038 токенов за 2.19 с с подчанками 1024; 5 038 токенов за 4.06 с
(≈1 240 tok/s); цепочка до резидентного контекста 15.8K; продолжение 26-28 tok/s; A/B против
холодного запуска: 41 идентичный токен, затем расхождение формулировок (принято). Записан
нижний порог приёма крошечного суффикса ~0.6 с.

## Почему это важно для стохастической линии

Резидентное состояние — предпосылка всего, что делает стохастический движок: его можно
продолжать, расширять без повтора, разветвлять в поля ветвей и дообусловливать. Форк, с которого
начинается каждый полевой эксперимент, — копия состояния, созданного этой механикой; чек форка
(ранний фриз) установил восемь физически независимых причинных потомков одного родителя без
повтора.
