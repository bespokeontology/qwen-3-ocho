# Ограничения

## Происхождение исходников AMD (блокирующее)

Точное дерево исходников, породившее замороженный продуктовый бинарник AMD (824e5c50…), не
восстановлено. Доступное зеркало лишь частично сверено по хешам с фриз-записью. Контролируемые
пересборки (с radix-селектором и без него) расходятся на токене 0 с замороженным бинарником,
поэтому порт оправдан, а пересборка лишена происхождения. Продуктовая работа AMD заморожена,
пока археология исходников не восстановит и не сверит по хешам истинное дерево. Порт radix
сохранён как экспериментальный, юнит-проверенный, ожидающий интеграции (patches/amd_pending/).

## Нативные 30 tok/s не достигнуты

Авторитетная ночная базовая линия: 29.70 tok/s на продуктовом рецепте с 8 038 токенами.
Сохранённое состояние после B1+B2: 29.44 tok/s (нетто +0.1 мс/токен, внутри дисперсии).
Оставшаяся дистанция ~0.34 мс/токен. Следующий механизм (слой QSA AMD — скоринг + внимание —
до байтового пола) заблокирован восстановлением происхождения выше.

## Стохастическая ширина M>8 не валидирована

При M=16 сигнатуры состояния второго слота имеют другой масштаб, а слот 0 дрейфует
относительно прогона M=8. M=8 — валидированная ширина; M=16 не публикуется как валидное
стохастическое масштабирование и имеет собственный раунд корректности.

## Пробелы Монте-Карло на модели

- Регионный протокол несёт только token id; построчных логарифмов вероятностей нет, поэтому
  взвешенный Монте-Карло на модели требует расширения протокола.
- Семплер модели сканирует весь словарь (~110 мс/шаг при M=8); семплер по ограниченному набору
  кандидатов — следующий механизм.
- MC-C сейчас односидовый: сид семплера читается при старте сервера, поэтому когерентность на
  двух сидах требует перезапусков сервера.
- sigR/sigK — детерминированные функционалы состояния ветви, используемые как наблюдаемые
  траектории; более широкая статистическая интерпретация не заявляется.

## Опасность замороженного бинарника (записано, не исправлено)

Рецепт форка требует QF_EXPERT_MODE=full. В режиме экспертов по умолчанию путь префилла
замороженного бинарника выполняет чтение за границей (свидетельство compute-sanitizer в чеках
B3 и MC-C) на чанках T=256. Исторически фактически используемый рецепт не затронут; опасность
задокументирована, потому что чек форка опустил переменную режима экспертов.

## Исключения из объёма

Спекулятивное декодирование/MTP, изменения квантизации, HIP-графы (отвергнуты более ранним
измерением) и любая переработка производительности M=8 вне объёма. Это дерево не делает
сравнительных заявлений против других обслуживающих систем; внешние числа требовали бы меток
по многим осям (нативно против спекулятивно, точность, контекст, аппаратура, конкурентность) и
не включены.
