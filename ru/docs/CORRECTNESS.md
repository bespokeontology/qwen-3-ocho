# Модель корректности

Побитовая идентичность не является универсальным требованием в этом проекте. У каждого
механизма свой гейт — минимальная физическая проверка, которая поймала бы неверную реализацию.
Гейты, использованные в сохранённой работе:

| гейт | механизмы | что устанавливает |
|---|---|---|
| тест с известным ответом | ГПСЧ | генератор соответствует замороженной спецификации (KAT на хосте и устройстве) |
| CPU-эталон | редукция Думитреску | слитые статистики совпадают с эталоном fp64 (14 случаев, допуски указаны) |
| аналитическое матожидание | MC-A / MC-A2 / MC-B / синтетическое поле | оценка совпадает с замкнутой формой в пределах ожидаемой ошибки Монте-Карло |
| токенная идентичность | B1, B2 | точная семантическая эквивалентность там, где правило этого требует (300/300) |
| дискриминатор eager против графа | B1 | замороженная область захваченного графа равна eager-области |
| юнит-набор против исходного алгоритма | B2, B3 | замена точно воспроизводит бисекцию (13 и 10 случаев) |
| compute-sanitizer memcheck | разработка B2, диагностика форка | нет выходов за границы |
| детерминированный повтор по сиду | MC-C, ГПСЧ | одинаковые входы воспроизводят одинаковые траектории |
| независимость ветвей | чек форка (ранний фриз) | принудительное возмущение токена двигает только возмущённую строку |
| сигнатуры состояния | MC-C | наблюдаемые траектории следуют за ветвью (sigR следует за токенами) |
| причинно-эквивалентное продолжение | доливка (ранний фриз) | возобновлённое состояние даёт связное продолжение |
| хеш-происхождение | все сохранённые бинарники | каждый артефакт адресуется SHA256 и фриз-записью |

Порядок важен: сначала дешёвый юнит-гейт (минуты), затем сквозной чек. В этом окне юнит-гейты
поймали до всяких чеков три дефекта селектора B2 (неопределённый сдвиг в маске префикса прохода
0, порог в по-поточных регистрах при том, что продвигает его только поток 0, потерянный сдвиг
ранга), один дефект взвешенного гейта (экстрактор равномерного применён к сырому слову вместо
word>>8) и один в редукции (ширина строки разделяемой памяти без трёх столбцов). Сквозной
токенный гейт существует именно для класса дефектов, которые юнит-тест пропускает; сохранены оба.

Единственный авторитет по качеству вывода — оператор; агенты измеряют и докладывают.
