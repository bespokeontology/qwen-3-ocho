# Интегрирование Монте-Карло

Числовое ядро движка валидировано на интегралах с замкнутой формой. Все гейты сливают выборку,
вычисление подынтегральной функции и редукцию в одно ядро; CPU никогда не итерирует по выборкам.
ГПСЧ: Philox4x32-10 по замороженной спецификации. Редукция: примитив Думитреску (fp64).
Аппаратура: NVIDIA GB10, зафиксированные частоты. Везде seed 42. Чек (авторитет):
receipts/MC_GATES_RECEIPT_20260907.md.

## MC-A — скалярная проверка

Задача: E[X²] для X ~ U(0,1). Аналитика: 1/3. Подынтегральная: f(x)=x². Без весов.
N = 1 048 576. Оценка 0.333674980. |ошибка| = 3.4e-4 (ожидаемая 1-sigma ~2.9e-4). Время
1.9 мс; ~5.4e8 выборок/с.

## MC-A2 — взвешенный (выборка по значимости)

Тот же интеграл, выборка по значимости из q(x)=2x на [0,1]: x=sqrt(u), w=1/(2x).
Оценка 0.333907284, |ошибка| = 5.7e-4, ESS ~3.1e5. Сквозная проверка взвешенного пути
(логарифмы весов, взвешенные моменты, отчёт ESS).

## MC-B — многомерный

Задача: E[Σ_j X_j²] по [0,1)^16. Аналитика: 16/3. 16 равномерных на выборку (4 слова Philox за
вызов). N = 262 144. Оценка 5.334712595, |ошибка| = 1.4e-3. Время 0.65 мс; ~4.1e8 выборок/с.
Проверяет векторизованный ГПСЧ и многомерную редукцию.

## MC-A3 — стратифицированный (снижение дисперсии)

Стратифицированная выборка, S=64 страт: u = (страта + uniform)/64. Тот же интеграл, что MC-A.
N = 1 048 576. Оценка 0.333335152, |ошибка| = 1.8e-6 — примерно в 188 раз меньше абсолютной
ошибки, чем обычная MC-A, при сравниваемом wall-time (обе ~1.9 мс). Это сохранённый механизм
снижения дисперсии. Это не «Монте-Карло в 188 раз быстрее», а ошибка в 188 раз ниже при равном
времени. Чек: receipts/VARIANCE_REDUCTION_RECEIPT_20260907.md.

## Почему важна эта метрика

Для систем такого класса выборок/с недостаточно. Важны: выборок/с, эффективных выборок/с,
ошибка оценки, ошибка оценки при фиксированном wall-time, ESS, траекторий/с. Цель оптимизации —
статистическая работа в секунду, а не только токены или выборки в секунду. Стратифицированный
результат — конкретная демонстрация: то же время, на два порядка меньше ошибки, изменено только
правило выборки.

## На модели (MC-C)

Мост от синтетического интегрирования к интегралу по резидентной модели — MC-C, описанный в
docs/STOCHASTIC_ENGINE.md и receipts/MCC_MODEL_FIELD_RECEIPT_20260907.md: один резидентный
родитель, семь стохастических потомков температуры 1, один жадный контроль, шестнадцать шагов,
сигнатуры состояния как наблюдаемые, редукция в статистику поля. Для условной по модели
наблюдаемой нет замкнутой формы; гейтом там служат детерминированный повтор по сиду и жадный
контроль, а аномалия M>8 записана как ограничение, а не результат.
