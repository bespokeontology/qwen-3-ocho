# Provenance and authority

This publication tree is a sanitized derivative of the canonical overnight freeze package
FREEZE_QWEN_OVERNIGHT_20260907 (with its internal SHA256SUMS and tarball
qwen_overnight_20260907_canonical.tgz). Where this tree and the package disagree, the package wins.

## Authority hierarchy

1. Canonical overnight freeze package + SHA256SUMS.
2. Frozen receipts and engineering reports inside that package.
3. Production Spark source: m8-amd-routed @ 420bca8 (not included in this tree; see below).
4. Lane B: m1-30tok-0907 — B1 12652f0, B2 f76ebeb.
5. Lane A: stoch-engine-0907 — 01e5d28, 148f740, b4bb1d2.
6. Frozen AMD production binary: 824e5c50… (SHA256SUMS in the package).
7. AMD source mirrors: NOT authoritative for that binary.

## Provenance labels used in this tree

| label | meaning |
|---|---|
| AUTHORITATIVE | committed in a frozen branch and present in the canonical package |
| HASH-VERIFIED | byte-identical to a canonical package entry (checked against package_SHA256SUMS) |
| PATCH-DERIVED | extracted from a frozen branch commit; meaningful only as part of that repository |
| SANITIZED COPY | derived from a canonical receipt with host addresses, home paths, and model paths replaced |
| EXPERIMENTAL | unit-verified mechanism without a production integration receipt |
| PENDING-PROVENANCE | source not recovered; no claim of reproducibility |

## Sanitization performed on receipts

The public receipts replace the private AMD host address with <amd-host>, other private LAN
addresses with <mac-host>, home directories with ~, and the model directory with
~/models/<checkpoint>. No numbers, timings, tokens, or commands were otherwise altered. The raw
receipts remain in the canonical package.

## Reproducibility boundaries

- The standalone stochastic kernels (RNG, reduction, MC gates, synthetic field) build and run from
  stoch/ on any CUDA GPU >= sm_70.
- Lane B patches apply only to the production repository (m8-amd-routed @ 420bca8), which is not
  part of this tree.
- Model-backed experiments (MC-C, decode receipts) require the two-box appliance and the frozen
  binaries; the frozen AMD production binary's source is PENDING-PROVENANCE.
